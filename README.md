# 未解檔案｜Unsolved Files

一款以劇情探索、現場蒐證、人物詢問與邏輯推理為核心的網頁推理遊戲。

玩家將扮演案件調查者，透過調查犯罪現場、蒐集證物、詢問嫌疑人及整理線索，逐步還原事件真相，最終找出案件背後的真相。

## 遊戲介紹

**CASE 001：雨夜的最後證言**

一場發生於雨夜的神祕死亡事件，讓原本平靜的宅邸籠罩在疑雲之中。

看似普通的現場物品、彼此矛盾的證詞，以及隱藏在時間線中的細節，都可能成為破解案件的關鍵。

玩家必須仔細觀察、分析證據，並運用邏輯推理完成調查。

## 主要遊戲功能

- **現場調查：** 自由切換調查地點，點擊場景中的可疑物品尋找線索。
- **證物檔案：** 收集並查看案件相關證物。
- **嫌疑人詢問：** 與案件相關人物對話，取得證詞與情報。
- **證據質問：** 使用已取得的證物，針對人物證詞提出質疑。
- **線索關聯：** 將不同線索建立關聯，發現新的推理方向。
- **偵探手札：** 整理調查紀錄與重要發現。
- **案件推理：** 整合證據與證詞，逐步還原事件經過。
- **結案判斷：** 根據調查結果提出最終推論。

## AI 功能

本遊戲設計了 AI 輔助的角色詢問功能，讓玩家可以透過文字向案件人物提出問題。

為避免 API 額度不足影響遊戲進行，系統也提供離線備援對話機制。

目前預設使用離線模式，AI 自由詢問需要另外設定 API。

## 執行方式

1. 下載專案程式碼。
2. 安裝 Python 與專案所需套件。
3. 在專案資料夾執行：

```bash
pip install -r requirements.txt
```

4. 啟動 Flask：

```bash
python app.py
```

5. 依照終端機顯示的網址，使用瀏覽器開啟遊戲。

## 開發狀態

目前 CASE 001 已建立主要遊戲系統，包含現場調查、證物管理、人物詢問、線索關聯及案件推理。

專案仍在持續開發與測試中，部分介面、美術素材與遊戲操作流程可能繼續調整。

## 開發目標

希望打造一款結合傳統文字推理遊戲與現代網頁互動技術的偵探遊戲，讓玩家不只是閱讀故事，而是能夠親自調查案件、整理線索並推導真相。

未來預計持續改善遊戲體驗，並探索多案件擴充的可能性。
